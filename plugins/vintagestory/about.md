# Vintage Story Format Support

Import, edit, and export models in the Vintage Story shape format, including animations and attachment points.

## Requirements

Blockbench **5.0.0 or newer**, desktop edition. Set **Game Path** under **File > Preferences > Settings > General** to your Vintage Story installation folder so the plugin can locate base-game textures.

## Getting started

- Open a Vintage Story shape JSON file with **File > Open Model**.
- Create a model with **File > New > Vintage Story Base Format**.
- Use the Vintage Story actions in the **Import** and **Export** menus to exchange shape files.
- The plugin also provides attachment tools and a **VS Face Properties** panel for glow, reflective mode, and wind properties.
