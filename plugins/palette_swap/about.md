# Palette Swap

Fast palette swap for Blockbench. Texture colors are grouped into **families by hue**, and a whole family of shades can be recolored to a new color in one move — while **preserving the light and shadow**. The interface is bilingual (English / Russian).

## How to use

1. Select a texture (optionally mark a selection area first).
2. Open **Tools → Palette Swap**.
3. Adjust the **grouping strength** to control how shades are clustered into families.
4. Give each family a new target color — with the color picker or the **eyedropper** (works on the model too).
5. The result previews live on the model. Press **Apply** to commit it (supported by Undo).

**Tips**
- Generate a family's new shades with the built-in gradient generator, or edit each shade individually.
- Selection-aware: if a pixel selection is active, only that area is affected.
