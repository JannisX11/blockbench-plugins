# Clean Animation Speed

Changes animation speed while snapping stays integer and keyframes land exactly on whole positions — no fractional numbers on the timeline. Can also fix an already broken (fractional) snapping.

## Usage

Open it from the "Animation" menu → "Speed (no fractions)" with an animation selected. Unlike the built-in dialog, snapping here is always an integer, so keyframes never drift onto fractional positions.
