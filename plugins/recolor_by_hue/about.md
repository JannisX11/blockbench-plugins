# Recolor by Hue

Shift hue / saturation / lightness / contrast of a texture or selection. Live preview on the model.

## Usage

Select a texture (and optionally mark an area in Paint mode), then open it from the Tools menu. Changes appear on the model instantly; the active selection is respected.
